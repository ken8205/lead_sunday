# 보류 중인 아이디어 (나중에 상의)

원칙: 쉽고, 간단하고, 빠르고, 재미있게. 복잡해지면 줄인다.

## 대기 경고 단계 (구현됨)
대기/호출 대기 카드: 10분 이상 빨강(정지) → 15분 이상 깜박(느리게) → 20분 이상 더 빠르게 깜박. 기준 분은 설정에서 바꾸며, 15/20분은 "기준 +5/+10분"입니다.
퇴원대기: 30분 이상 초록색 깜박(설정에서 변경). 퇴원대기 시간은 "퇴원대기가 된 때"부터 셉니다(방을 옮겨도 유지).
- 미정: 진행 중 상태에도 경고를 줄지.

## 5단계에서 보류한 것
- 설정 화면에서 방을 **끌어서 옮기고 크기 조절** (지금은 숫자 입력). 복잡해서 뒤로 미룸.
- 방 배치 초기화 버튼 (카드가 있는 사용자 방과 충돌 처리 필요).
- 대기 시간을 "준비 완료가 된 시점"부터 셀지 ("방 입실" 기준은 지금 그대로).
- 호출 대기 순서(수동)를 원장 보기에서도 조절할지. 지금은 보드에서만 조절하고 원장 보기는 따라감.
- 분류(상담/수술/치료/경과/미팅)별 색·필터. 지금은 카드에 글자로만 표시.
- 한 방에 카드가 방 크기보다 많아지면 방 밖으로 넘침 (지금은 방을 크게 잡아 완화). 넘침 표시(+N)나 자동 확대 필요.
- 미팅은 지금 "환자 카드"와 같은 방식으로 다룸. 별도 구분(색, 필터)은 미정.

## 보류: CRM 엑셀로 환자 카드 자동 만들기 (나중에 상의)
원장님 요청(2026-10): CRM 예약조회 엑셀을 올리면 상담/수술/치료/경과로 구분된 카드가 자동으로 만들어지고, 그 카드를 평면도로 끌어서 바로 추가. 기존 "+ 환자 추가"는 그대로 유지.

정해진 것
- 엑셀에서 **4개 칸만** 읽는다: `고객명`(이름), `생년월일`, `시수술`(수술/시술명), `세부부서`(분류: 상담/수술/치료/경과 등).
- 그 외 칸(연락처, 차트번호, 주민등록번호 등)은 **읽지도 저장하지도 않는다.** 주민등록번호는 엑셀에서 빼고 내려받길 권장.
- 분류는 시술명 추측이 아니라 **세부부서 칸**을 그대로 쓴다. 4개 외의 값은 미리보기에서 "분류 확인 필요"로 표시하고 직접 고른다.
- 엑셀은 **브라우저 안에서만** 읽는다(서버로 파일을 올리지 않음). 서버에는 확정한 카드만 저장.

만드는 순서(제안)
1. 엑셀 올리기 + 미리보기(표로 확인·수정, 아직 저장 안 함)
2. "예정 환자" 영역: 확정한 목록을 서버에 저장해 모든 직원이 공유(7일 후 자동 삭제). 새 서버 표 + SQL 필요.
3. 예정 카드를 평면도 방에 끌어서 놓으면 보드 카드로 추가(예정 영역에서는 사라짐)
- 중복 방지: 이미 보드에 있는 환자는 "이미 있음" 표시

아직 모르는 것(재개할 때 확인)
- 비밀번호: 보내 주신 샘플은 비밀번호 걸린 zip이라 열지 못했다. 평소 CRM에서 내려받는 파일에 비밀번호가 있는지(zip/엑셀) 확인 필요. 있으면 올릴 때 비밀번호 입력창을 띄워 브라우저 안에서 풀도록 만들 수 있고, 없으면 엑셀을 그대로 올리면 된다.
- 생년월일 칸 표기 형식(1975-03-14 / 1975.03.14 / 750314 / 19750314). 6자리는 세기가 헷갈려 미리보기에서 확인.
- 엑셀에 하루치만 있는지, 여러 날짜가 섞였는지(섞였으면 "오늘 날짜만" 선택 필요).
- 세부부서에 4개 외의 값이 있는지.
- 가능하면 비밀번호 없는 가명 샘플 5~10줄(맨 윗줄 항목 이름은 그대로).
