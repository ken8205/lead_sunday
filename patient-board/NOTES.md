# 보류 중인 아이디어 (나중에 상의)

원칙: 쉽고, 간단하고, 빠르고, 재미있게. 복잡해지면 줄인다.

## 대기 경고 단계 (제안, 미구현)
대기/준비 완료 카드에 적용. 현재는 기준 시간(기본 10분) 한 단계만 빨간 테두리.

| 대기 시간 | 표시 |
| --- | --- |
| 5분 이상 | 노랑 (깜박임 없이 테두리) |
| 10분 이상 | 빨강, 천천히 깜박 |
| 15분 이상 | 빨강, 빠르게 깜박 |

- 기준 분(5/10/15)은 설정 화면에서 변경 가능하게.
- 처음부터 모두 깜박이면 알람 피로로 급한 것이 묻힐 수 있음 (환자 모니터 알람 영역의 알려진 개념이며, 이 보드에서의 효과는 확인된 바 없음 → 써 보고 조절).
- 속도 연속 증가보다 2단계 속도가 단순함.
- 미정: 진행 중 상태에도 적용할지, 경과 시간 기준을 "방 입실"로 둘지 "준비 완료 시점"으로 둘지.
