# 커리큘럼 로드맵

각 트랙은 3단계(기초 → 중급 → 심화)로 구성됩니다. 아래는 **1단계(기초)**를 구체적으로 제시합니다. 1단계를 마친 뒤 중급·심화 단계는 그때까지의 관심사와 진도를 반영해 해당 트랙 튜터와 함께 다시 설계합니다 — 지금 20년 뒤까지 못박아 두는 것은 무의미합니다.

각 트랙의 1단계는 독립적으로 시작 가능하며, 순서를 꼭 지킬 필요는 없습니다. `dean`이 매주/매분기 어떤 트랙을 다룰지 제안합니다.

**이것은 교양 강좌가 아니라 도제식 사사(師事)입니다.** 각 튜터 에이전트(`.claude/agents/*.md`)는 해당 분야 역사상 최고 대가들의 방법론을 체화하고 있으며, 표면적 개관을 금지하고 있습니다. 아래 목록의 각 항목은 실제로는 여러 세션(짧은 텍스트도 2~3회, 장편 저작은 5~10회)에 걸쳐 다뤄지며, 매 세션 원장님이 직접 증명·번역·해석·계산 등 산출물을 내야 다음으로 넘어갑니다. 정확한 세션 배분은 각 튜터 에이전트 파일에 예시로 제시되어 있습니다.

---

## 문학 (고전, 동서양) — `classics-tutor`

**서양:** 호메로스(『일리아스』·『오뒷세이아』) → 그리스 비극(소포클레스·아이스퀼로스·에우리피데스) → 베르길리우스(『아이네이스』) → 단테(『신곡』) → 셰익스피어 4대 비극 → 세르반테스(『돈키호테』)

**동양:** 『논어』·『맹자』 → 『노자』·『장자』 → 사마천 『사기』 열전 → 한국고전(『삼국유사』, 박지원 『열하일기』)

## 역사 — `history-tutor`

헤로도토스 『역사』(페르시아 전쟁) → 투키디데스 『펠로폰네소스 전쟁사』 → 사마천 『사기』(본기·열전으로 보는 중국 고대사) → 로마사 개관 → 한국사 통사(고대~조선) → 근현대사(산업혁명, 세계대전, 냉전)

## 철학 (동서양) — `philosophy-tutor`

**서양:** 플라톤(『국가』·『향연』·『변명』) → 아리스토텔레스(『니코마코스 윤리학』) → 스토아철학(마르쿠스 아우렐리우스·에픽테토스·세네카) → 데카르트 → 칸트

**동양:** 『논어』·『맹자』의 윤리학적 독해 → 『노자』·『장자』의 형이상학 → 불교철학 입문(『반야심경』·『금강경』) → 한국유학(이황·이이의 이기론)

## 수학 — `math-tutor`

유클리드 『원론』(공리적 방법) → 미적분의 개념적 재구성 → 선형대수(기하적 직관) → 확률론 기초 → 통계학(가설검정·신뢰구간·회귀 — 임상연구 논문을 읽어낼 수준) → (여력 시) 정수론/위상수학 입문

## 자연과학 — `science-tutor`

과학적 방법론(베이컨의 귀납법, 포퍼의 반증가능성) → 고전역학(뉴턴 『프린키피아』 발췌) → 진화생물학(다윈 『종의 기원』 + 현대종합) → 해부학·생리학사(베살리우스, 하비) → 화학 기초(원자론사) → 현대물리학 개관(상대성이론·양자역학의 개념)

## 공학 — `engineering-tutor`

공학적 사고(문제 정의·제약조건·최적화) → 역학 기초(힘·응력·변형) → 재료의 기초(강도·탄성·피로) → 데이터 리터러시/컴퓨팅 사고 → 시스템 사고(피드백 루프·병목·신뢰성 공학)

## 통섭 포인트 (예시 — 그랜드 신테시스 세션용)

- 그리스 수사학 ↔ 임상 커뮤니케이션 (설득의 구조)
- 다빈치의 인체 소묘 ↔ 베살리우스 해부학 ↔ 원장님의 안면해부학 (관찰이 지식이 되는 과정)
- 스토아 철학의 "통제 가능한 것/아닌 것" 구분 ↔ 확률·통계의 불확실성 다루기
- 사마천의 역사 서술 방식 ↔ 근거 계층(1차 사료 vs. 해석) ↔ evidence-based medicine의 근거 계층
- 공학의 트레이드오프 분석 ↔ 1인 클리닉 운영의 자원 배분 문제

이런 연결은 억지로 만들지 않습니다. 실제로 공부하다가 자연스럽게 떠오를 때 `dean`이 짚어줍니다.
