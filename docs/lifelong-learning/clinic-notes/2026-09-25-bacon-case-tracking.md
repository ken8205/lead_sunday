# 베이컨의 표 — 케이스 추적을 시작하는 법

- 원본 세션: `notes/2026-09-25-science-bacon-1.md`
- 날짜: 2026-09-25

## 오늘의 학습 요약

베이컨의 귀납법은 "존재의 표"(성공 사례)만이 아니라 "부재의 표"(그 방법을 안 썼는데도 좋았던, 혹은 썼는데도 나빴던 사례)를 의도적으로 모아 비교할 것을 요구한다. 인간은 본능적으로 존재의 표만 기억한다.

## 오늘 세션에서 이미 나온 구체적 적용

이 세션 자체가 이미 실전 적용까지 이어졌습니다. 정리하면:

1. **용어 정밀화 프로젝트.** "SMAS 테크닉"(플리케이션·심플 익시전 등을 뭉뚱그림)과 "칸토팩시"(실제로는 오비큘라리스 서스펜션을 하면서 칸토팩시라 부르는 경우) — 이 두 용어부터 원장님 스스로 더 정밀한 기준으로 재정의해볼 만합니다. 차트·동료 간 소통에서 실제 술식을 정확히 지칭하는 것만으로도 시장의 우상을 상당 부분 제거할 수 있습니다.
2. **케이스 추적 3단계 로드맵**:
   - **1단계(지금 바로, 코드 불필요)**: 안검하수 케이스마다 술전 처짐 정도, 교정 여부, 이마 보상 정도, 술후 결과, 추적 기간을 엑셀/구글시트에 한 줄씩 기록.
   - **2단계(20~30케이스 누적 시)**: 필터·정렬만으로 패턴 확인 (예: "이마 보상 2단계 이상이면 교정 안 해도 결과 좋음" 같은 가설 검증).
   - **3단계(패턴이 실제로 유용하다고 확인된 후)**: 구조화된 코드 시스템으로 이전 — 이 시점에 실리프팅 지속기간 등 다른 시술도 같은 틀로 통합 가능.
3. **환자 데이터 취급.** 실제 케이스 데이터인 만큼, 처음부터 환자 이름 대신 코드번호를 쓰는 습관 등 비식별화를 전제로 설계해야 함 — 나중에 코드 시스템으로 옮길 때는 개인정보보호법·의료법상 요건 검토 필요.

## 생각해볼 질문

- "SMAS 테크닉"이라는 이름 대신, 원장님이 실제로 하시는 술식들을 어떻게 더 정확히 구분해서 부르고 싶으신가요?
