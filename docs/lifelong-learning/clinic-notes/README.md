# 클리닉 노트

학습 세션(`notes/`)이 "무엇을 배웠는가"를 정리한다면, 이 폴더는 **"그것이 내 클리닉/일에 어떻게 적용되는가"**를 정리합니다. 학문적 통찰을 실무 자산으로 전환하는 것이 목적입니다.

## 원칙

- **강요하지 않는다.** 모든 세션이 클리닉에 적용될 만한 통찰을 주는 건 아니다. 억지 연결은 만들지 않고, 진짜 쓸모 있는 연결이 있을 때만 기록한다.
- **처방이 아니라 질문으로 끝낸다.** 이 문서들의 목적은 "이렇게 하세요"라는 결론이 아니라, 원장님이 실제 판단을 내릴 때 참고할 사고의 재료를 쌓는 것이다. 그래서 가능하면 구체적 액션 아이디어와 함께, 원장님 스스로 판단할 수 있도록 반성적 질문을 남긴다.
- **사업의 실제 맥락과 연결한다.** 1인 클리닉 운영, 해외 환자 비중, 실장/직원 관계, evidence-based 진료 문화 같은 원장님의 실제 상황을 참고하되, 확실히 아는 것과 추측을 구분한다.

## 형식

```
# [세션 주제] — 클리닉 노트

- 원본 세션: notes/YYYY-MM-DD-....md
- 날짜: YYYY-MM-DD

## 오늘의 학습 요약 (1~2문장)

## 클리닉에 적용해보면

(구체적 적용 아이디어. 여러 개일 수 있음)

## 생각해볼 질문

(원장님이 직접 판단하도록 남기는 질문 1~2개)
```
