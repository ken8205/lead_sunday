# 평생학습 프로그램 — 고전·문사철·수학·과학·공학

원장님의 평생학습을 위해 구성한 Claude Code 서브에이전트 기반 학습 시스템입니다. 1인 클리닉을 운영하는 바쁜 일정 속에서도 수십 년에 걸쳐 지속 가능한 리듬으로 고전(문학·역사·철학)과 수학·과학·공학을 원전 중심, 근거 기반으로 공부하기 위해 만들었습니다.

## 구성

**학장 (`dean`)** — 전체 커리큘럼을 관리하고, 주간/분기 리듬을 조율하며, 여러 분야를 가로지르는 통섭적 연결을 짚어주는 총괄 에이전트.

**여섯 개 트랙 튜터:**

| 에이전트 | 담당 |
|---|---|
| `classics-tutor` | 고전문학 (동서양) |
| `history-tutor` | 역사 |
| `philosophy-tutor` | 철학 (동서양) |
| `math-tutor` | 수학 |
| `science-tutor` | 자연과학 |
| `engineering-tutor` | 공학 |

각 에이전트 정의는 `.claude/agents/*.md`에 있습니다.

## 사용법

Claude Code에서 특정 에이전트를 지정해 대화를 시작하면 됩니다. 예:

- "학장 에이전트로 이번 분기 리뷰하자" → `dean`
- "고전문학 튜터로 오늘은 안티고네 읽자" → `classics-tutor`
- "수학 튜터로 베이즈 정리 증명해줘" → `math-tutor`

무엇부터 할지 모르겠으면 그냥 `dean`을 불러서 "오늘 뭐 할까요"라고 물으면 됩니다. 학장이 `curriculum.md`와 `study-log.md`를 보고 제안합니다.

## 학습 철학

1. **원전 우선.** 해설서보다 원문(또는 좋은 번역본)을 먼저 읽는다.
2. **근거 기반.** 과학·역사·철학 모든 주장에서 "확실한 것 / 주류 해석 / 논쟁 중인 것 / 추측"을 구분한다. 원장님이 임상에서 쓰는 evidence-based 원칙을 인문학에도 그대로 적용한다.
3. **소크라테스식 대화.** 답을 바로 주기보다 질문으로 이끈다.
4. **인터리빙.** 한 주에 깊이 파는 트랙 1개 + 가볍게 복습하는 트랙 1개를 병행한다. 한 과목만 몰아서 하지 않는다.
5. **통섭.** 분기(3개월)마다 그 기간 다룬 여러 트랙을 하나의 질문으로 꿰어보는 "그랜드 신테시스" 세션을 갖는다.
6. **지속 가능성.** 평생 프로젝트다. 속도보다 리듬을 지키는 것이 중요하다.

## 문서

- `curriculum.md` — 트랙별 로드맵 (1단계: 기초, 약 2~3년 분량을 구체적으로 제시)
- `study-log.md` — 세션 기록. 매 세션 끝에 날짜·트랙·핵심 통찰을 짧게 남긴다.
- `notes/` — 세션별 복습 노트("교재"). `study-log.md`가 짧은 진행 기록이라면, `notes/`의 각 파일은 그 세션 하나를 교재처럼 완전히 정리한 문서다(배경·핵심 개념·용어·복습 질문·다음 예고). 파일명 규칙: `YYYY-MM-DD-트랙-주제-세션번호.md`. 원할 때 이 내용을 HTML Artifact로도 시각화해서 볼 수 있다.

## 권장 주간 리듬 (예시, 주 3~5시간 기준)

- 평일 중 30~40분 ×2~3회: 깊이 파는 트랙의 원전 읽기 + 에이전트와 토론
- 주말 1회 30분: 복습 트랙 또는 노트 정리
- 분기 1회: 학장과 함께 그랜드 신테시스 세션

시간이 부족한 주에는 양보다 리듬 유지를 우선하십시오. 하루 10분씩 원전을 읽는 것만으로도 충분합니다.
