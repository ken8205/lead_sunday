# 페이스플러스 상담 통계

문의 한 건을 한 줄로 기록하는 **상담 대장**과, 내원경로·마케팅 효과를 보는 **통계** 화면입니다 (병원 직원 전용).
환자 동선 보드(`../patient-board`)와는 별도 앱이며, 나중에 합칠 수 있도록 같은 기술(React + Vite + Supabase)과 같은 직원 계정 구조를 씁니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 타입 검사 + 배포용 빌드 (dist/)
```

## 화면

- **상담 대장** (전 직원): 인콜·카카오채널·강남언니·네이버예약 등 어디로 들어온 문의든 한 건씩 기록합니다. 기록 항목은 문의 채널, 유입 경로, 광고·이벤트 이름, 국적, 관심 시술, 단계, 결제 금액입니다. 이름·연락처·생년월일은 받지 않습니다.
- **통계** (원장·실장만): 기간(오늘·어제·특정 하루, 이번 달·최근 3개월·최근 12개월·올해·작년 등)을 고르면 요약 숫자, 항목별 표(경로·채널·국적·시술·광고), 주별·월별·연도별 추이가 나옵니다. 경로별 월 광고비를 입력하면 결제 1건당 광고비와 광고비 대비 매출도 계산됩니다.
- **항목 상세**: 항목별 표에서 이름(예: 네이버 검색)을 누르면 그 항목만의 요약, 주별·월별·연도별 추이, 다른 항목으로 나눠 보기, 문의 목록이 나옵니다. 주소에 화면과 기간이 들어가므로 링크를 직원에게 보내면 같은 화면이 열립니다(로그인 필요).
- **항목 관리** (전 직원): 문의 채널, 유입 경로, 국적, 관심 시술 목록을 추가·순서 변경·삭제합니다. 이 순서대로 "새 문의" 화면에 버튼이 나옵니다. 지워도 이미 기록된 문의와 통계는 그대로 남습니다.
- 하루 통계: 그날 들어온 문의의 단계·경로와 함께, 그날 결제된 건(결제일 기준, 예전 문의 포함)을 따로 보여 줍니다. 광고비는 월 단위라 하루 통계에는 나오지 않습니다.
- 집계 기준: 문의일. 주는 월요일 시작(ISO 8601). 건수 10건 미만의 비율은 흐리게 표시합니다.

## 서버 모드

환경 변수 두 개가 있으면 로그인 + 서버 저장, 없으면 이 브라우저에만 저장하는 시험 모드입니다.

```
VITE_SUPABASE_URL=https://<프로젝트>.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...   # 공개용 키만. secret/service_role 키는 절대 넣지 않음
```

- Supabase SQL Editor에서 `supabase/schema.sql`을 실행합니다 (여러 번 실행해도 안전).
- **동선 보드와 같은 Supabase 프로젝트**에 실행하면 직원 계정을 그대로 씁니다 (권장: 직원이 계정 하나로 두 앱 모두 로그인).
- 새 프로젝트에 실행하면 직원 계정을 따로 만들어야 합니다 (`../patient-board/supabase/create-staff.sql` 참고).
- 대장 삭제와 광고비 입력·조회는 원장·실장만 가능합니다 (서버에서 막음).
- 대장은 통계용이라 자동 삭제하지 않습니다.

## 배포 (Vercel)

동선 보드와 같은 방식으로 **Vercel 프로젝트를 하나 더** 만듭니다. Root Directory는 `inquiry-stats`, Framework는 Vite, 환경 변수는 위 두 개입니다.
배포 주소를 열었을 때 로그인 화면이 나오는지 꼭 확인하세요 (환경 변수가 없으면 로그인 없는 시험 모드로 열립니다).
