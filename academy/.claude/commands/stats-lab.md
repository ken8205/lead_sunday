biostatistician 에이전트로 `curriculum/02-stats-track.md`의 다음 회차를 진행한다(진도는 tracker 참조, $ARGUMENTS 로 회차 지정 가능). 순서: 학습자의 임상 질문 → 변수·설계 정하기 → 도구(jamovi/JASP→R)에서 클릭/코드 단계별 실습 → 결과 해석을 학습자가 직접 말해보기 → 흔한 오해 교정 → 결과물 저장(`research/stats-labs/`). 연습 자료는 가상 또는 비식별 데이터만 사용. 첫 회(S0)는 현재 수준과 설치 상태 진단.
