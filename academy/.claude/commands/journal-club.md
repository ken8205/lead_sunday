description: 논문 1편 정밀 비판적 읽기 (저널클럽)
---

$ARGUMENTS 의 논문(PMID/제목/PDF 경로)을 evidence-librarian이 PubMed로 확인한 뒤, 해당 분야 교수가 진행한다. 구조: 연구 질문 → 설계와 표본 → 평가 지표(검증 여부) → 통계 방법(biostatistician) → 결과 해석 → 편향·한계 → 이해상충 → 임상 적용성 → 근거 수준 판정 → 학습자 의견 토론 → 이 논문에서 파생되는 연구 질문. 논문 전체 복제는 하지 않고 요약·평가한다. 노트는 `notes/journal-club/`에 저장.
