# 모듈 2~8 개요 (눈 모듈 이후 순차, 순서는 학습자 요청에 따라 조정)

공통 구조: 역사(계보) → 현재 표준 → 논쟁 → 연구 공백 → 학습자 증례 토론. 각 모듈 서지는 evidence-librarian이 PubMed로 검증해 `notes/<모듈>/references.md`에 구축.

## A. 안면 해부·노화 심화 (8회) — anatomy-aging

## 2. 실리프팅 (10회) — thread-lift

## 3. 보툴리눔 톡신 (8회) — neuromodulator

## 4. 필러 (10회) — filler

## 권장 순서 (학습자 임상 빈도 반영, 조정 가능)
눈(+통계) → A 해부 → 실리프팅 → 필러 → 보툴리눔 → 스킨부스터 → 거상·경부 → 합병증(횡단, 각 모듈 말에 일부 선행) → 논문 작성
임상에서 시급한 주제(예: 필러 응급 대응)는 순서와 무관하게 앞당긴다.
