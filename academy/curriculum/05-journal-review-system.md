# 저널리뷰 중심 체제 (2026-10-04 학습자 요청으로 재편)

**원칙: 강의가 아니라 논문을 읽으며 배운다.** 해부, 통계, 방법론, 연구 아이디어는 모두 그 주의 논문에서 끌어낸다. (기존 모듈 계획서는 "파트별 주제 지도"로 재활용)

## 주간 구조 (기본값: 한 주 = 논문 4편, 파트 혼합 가능)
- **최신지견 2편**: 최근 2~3년 내 RCT, 체계적 고찰·메타분석, 대규모 코호트 우선. 개별 증례·기술 소개는 우선순위 낮음
- **이정표 2편**: 개념을 만들었거나 술기·판단 기준을 바꾼, 또는 오래 인용되는 논문. 선정은 Claude 제안 + 학습자 거부권. 선정 기준은 매번 명시하고 "주관적 판단[E]"로 표시

| 요일 | 내용 |
|---|---|
| 월 | 최신지견 #1 정밀 리뷰 |
| 화 | 이정표 #1 정밀 리뷰 |
| 수 | 통합·통계의 날: 이번 주 논문들의 통계 방법을 하나씩 해부 (통계 트랙을 여기서 흡수) |
| 목 | 최신지견 #2 정밀 리뷰 |
| 금 | 이정표 #2 정밀 리뷰 |
| 토 | 주간 종합 토론: "이 파트에서 확실한 것/불확실한 것/비어 있는 것" + 연구 아이디어 + 다음 주 논문 확정 |
| 일 | 가벼운 날: 퀴즈 또는 선택 읽기 |

PC 앞에 앉는 날은 수·토에 jamovi/R 실습을 덧붙인다.

## 파트 구성 (2026-10-04 갱신: 한 주의 4편은 서로 다른 파트여도 됨)
매주 4편을 가능하면 서로 다른 파트에서 고르고, 논문은 한 주치를 한꺼번에 제시한다(계획표 포함). 아래 파트 목록을 돌며 균형을 맞춘다.

파트 목록 (기존 한 주 한 파트 순환안은 폐기, 균형 점검용):
1 상안검·안검하수 → 2 하안검·눈밑지방 → 3 안면거상·경부·미니거상 → 4 실리프팅 → 5 필러 → 6 보툴리눔 → 7 스킨부스터·재생·에너지 → 8 안면 해부·노화 → 9 합병증·안전 → 10 측정·PROM·사진 표준화
파트별 누적 편수를 `reading-log.md`에서 점검해 소외된 파트를 우선 배정한다. 논문 대기열은 `notes/journal-club/backlog.md`.

## 논문 확보 규칙
1. Claude가 PubMed로 후보 선정, 서지·초록 검증, PMC 무료 전문 여부 확인
2. PMC에 전문이 있으면 Claude가 직접 읽고 리뷰
3. 없으면 학습자가 PubMed/Google Scholar/기관 경로로 PDF를 구해 채팅에 업로드 (모바일은 파일 앱 공유로 가능)
4. **전문을 못 본 논문은 초록 수준의 리뷰임을 명시**하고, 방법·통계 세부는 단정하지 않는다
5. 논문 원문을 장문 복제하지 않고 요약·평가한다

## 리뷰 형식 (`notes/journal-club/_template.md`)
연구 질문(PICO) → 설계·근거 수준 → 표본·선택 → 평가 지표(검증 여부, 눈블라인드) → 통계(분석 단위: 눈 vs 환자, 다중비교, 효과크기·CI, 결측) → 핵심 결과 수치 → 편향·한계(RoB 2 / ROBINS-I 틀) → 이해상충·후원 → 내 진료에 적용 가능성 → 미해결 질문 → 연구 아이디어 → 근거 확신도 판정 → 학습자 3줄 요약

## 학습 성과
- 매주 파트별 근거 지도 1장 (`notes/journal-club/week-NN-*.md`)
- 누적 문헌 DB (`notes/journal-club/reading-log.md`)
- 통계는 논문 해부를 통해 습득, 마지막에 직접 분석 프로젝트
