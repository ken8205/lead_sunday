# 통계·분석도구 트랙 (초심자 → 직접 분석)

주 교수: biostatistician. 원칙: 직관 → 임상 예시 → 실습. 수식은 필요할 때만.
도구: 1~4주 jamovi/JASP (GUI) → 5주 이후 R + RStudio 병행. 처음에는 학습자의 엑셀 자료 구조 정리부터.

| 회 | 주제 | 실습 | 임상 예시 |
|---|---|---|---|
| S0 | 진단 + 데이터란 무엇인가 | 변수 유형, 엑셀 자료 정리(tidy data), 비식별 코딩 | 상안검 수술 환자 컬럼 설계 |
| S1 | 기술통계와 그림 | 평균·중앙값·SD·IQR, 히스토그램·박스플롯 | MRD1 분포 |
| S2 | 불확실성: 표본과 모집단, SE, 신뢰구간 | CI 계산·해석 | 만족도 점수의 CI |
| S3 | 가설검정과 p값의 진짜 의미 | 1종·2종 오류, 효과크기, p값 오해 | "유의하다"가 의미하는 것 |
| S4 | 짝지은 자료: 수술 전·후 | paired t, Wilcoxon, 정규성 판단 | 수술 전후 MRD1 |
| S5 | 두 집단 비교 | t검정, Mann-Whitney, 변수 선택 | A술기 vs B술기 |
| S6 | 범주형 자료 | 카이제곱, Fisher, 위험비·오즈비 | 합병증 발생률 비교 |
| S7 | 상관과 단순 회귀 | 산점도, 상관, 회귀 해석 | 나이와 눈꺼풀 처짐 정도 |
| S8 | 다변량 회귀·교란 보정 | 선형회귀, 변수 선택의 함정 | 결과에 영향 주는 요인 |
| S9 | 이분형 결과: 로지스틱 회귀 | OR 해석, 모델 점검 | 합병증 위험인자 |
| S10 | 측정의 신뢰도·일치도 | ICC, Bland-Altman, kappa | 두 평가자의 MRD 측정 |
| S11 | 성형외과 특이 문제 | 양안 상관(눈 단위 vs 환자 단위), split-face, 반복 측정, 혼합모형 개념 | 양안 수술 데이터 |
| S12 | 표본 수·검정력·다중비교·결측 | 표본 수 계산 도구 사용 | 연구 계획 단계 |
| S13 | 문헌고찰·메타분석 기초 | forest plot 읽기, 이질성 | 체계적 고찰 논문 해부 |
| S14 | 종합 프로젝트 | 학습자 자료 전체 분석 → 결과 섹션 초안 | 눈 모듈 연구 |

## 도구 학습 경로
1. jamovi/JASP: 클릭 분석, 결과 해석 (4주)
2. R 기초: 데이터 불러오기, tidyverse 기초, ggplot2, 재현 가능한 스크립트 (5~12주)
3. 이후: 혼합모형, 메타분석 패키지, Quarto/R Markdown으로 보고서 자동화
