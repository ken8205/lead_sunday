# 로드맵

학습 리듬: 주 3회 이상(목표 매일). 평일 30~45분 마이크로 세션 + 주 2~3회 심화. 통계는 처음부터 실습 병행.

## Phase 0 — 준비 (1주)
- [ ] 현재 통계·도구 수준 진단 (10문항 퀴즈, `/stats-lab` 첫 회)
- [ ] 분석 도구 설치: jamovi(또는 JASP) → 이후 R + RStudio
- [ ] 학회 커리큘럼을 `inbox/conference-curricula/`에 투입 → gap 분석
- [ ] 연구 주제 후보를 평소 임상에서 3개 메모 (`research/ideas.md`)
- [ ] 비식별 데이터 정리 방식 합의 (엑셀 컬럼 설계)

## Phase 1 — 1~3개월: 처진눈 모듈 + 통계 기초 (병행)
- 눈 모듈 12회: `01-eyelid-module.md`
- 통계 12회: `02-stats-track.md`
- 월 1회 트렌드 브리핑 (trend-scout)
- 목표: 눈 모듈 종료 시점에 학습자의 실제 자료로 소규모 분석 완료 (예: 상안검 수술 전후 MRD1 변화)

## Phase 2 — 4~9개월: 주력 분야 순차 심화
순서(조정 가능): 안면 해부·노화 심화 → 안면거상·경부·미니거상 → 실리프팅 → 필러·보툴리눔 → 스킨부스터·재생·에너지 → 합병증·안전
각 모듈 구조: 역사(계보) → 현재 표준 → 논쟁 → 연구 공백 → 학습자 증례 토론
통계 트랙 2단계: 회귀·로지스틱·측정 신뢰도·메타분석 기초, R 스크립트로 이행

## Phase 3 — 10~12개월: 연구 실전
- 원장님 데이터로 논문 1~2편 설계·분석·작성
- 후보: 상안검 수술 환자 하수 감별과 결과 / 실리프팅 합병증 후향 분석 / 미니거상 PROM
- research-methods와 reviewer-2 주도, biostatistician이 분석 지도

## Phase 4 — 평생 유지 사이클
- 월간: 트렌드 브리핑
- 분기: 한 모듈 재방문(최신 근거로 갱신)
- 연간: 논문 프로젝트 1~2건, 학회 커리큘럼과 대조해 빈 곳 보강

## 이정표 논문 학습 방식
모듈마다 `notes/<모듈>/references.md`를 evidence-librarian이 구축한다. 분류: 개념 창시 / 술기 변화 / 반박·재평가 / 현재 표준·합의문 / 체계적 고찰. **모든 서지는 PubMed로 검증된 것만 [V]로 기록하고, 선정 기준이 주관적 판단임을 명시한다.**
