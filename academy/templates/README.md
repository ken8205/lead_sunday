# 연구용 엑셀 재추출 가이드 (Windows)

1. EMR/차트에서 먼저 **원본을 그대로** 뽑되, 이 폴더의 템플릿 컬럼 구조로 **새 파일**에 옮긴다. 원본은 클리닉 내부 보관.
2. **식별정보 제거**: 이름, 차트번호, 주민번호, 전화번호, 사진 파일명 제거. 대신 연구번호(`E001`…)를 부여한다. 연구번호↔환자 대조표는 별도 파일로 클리닉 내부에만 보관한다(채팅·저장소에 올리지 않는다).
3. 생년월일 대신 수술 시 **나이**, 날짜는 가능하면 "수술일 기준 경과일"로 변환. 희귀 질환 등 재식별 위험이 있는 자유서술은 제외.
4. 한 행 = 한 눈(혹은 한 환자) 원칙을 먼저 정한다. 좌우를 따로 쓰면 행이 눈 단위가 되어 통계 분석에 영향이 있으므로 `patient_id`와 `eye`(R/L) 컬럼을 둔다.
5. 한 칸에는 한 가지 정보만. 병합 셀, 색깔로 의미 표시, 한 칸에 "2mm/3mm" 같은 복수 값 금지. 결측은 빈칸으로.
6. 저장은 `.xlsx`와 `.csv(UTF-8)` 둘 다.
7. 이 채팅에 올리기 전에 위 2~3번을 다시 확인한다. 연구 목적 사용은 IRB와 개인정보 규정 확인이 선행되어야 한다(법률 판단은 소속 기관·전문가와 상의).

템플릿: `eyelid-surgery-template.csv` (상안검·하수·하안검 후향 분석용 예시 컬럼, 학습자 연구 질문에 맞게 S0 수업에서 수정)
