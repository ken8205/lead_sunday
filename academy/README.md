# Plastic Surgery Academy

안티에이징 얼굴성형 전문의를 위한 평생 학습 프로그램. Claude Code 에이전트(교수진)와 함께 진행합니다.

## 시작
1. 이 폴더(`academy/`)를 작업 디렉터리로 Claude Code를 엽니다 (나중에 독립 저장소로 옮기면 그대로 동작).
2. `/today` — 오늘 세션 시작
3. `/quiz` — 10분 복습
4. `/stats-lab` — 통계 실습
5. `/journal-club <PMID 또는 제목>` — 논문 정밀 읽기
6. `/ingest` — `inbox/`에 넣은 학회 커리큘럼 등 반영

## 구조
- `CLAUDE.md` 운영 규칙(근거 태그, 인용 검증, 개인정보)
- `.claude/agents/` 학과장 포함 14명
- `curriculum/` 로드맵·모듈·통계 트랙·리듬
- `notes/`, `progress/`, `research/`, `inbox/`

## 안전 수칙
환자 개인정보·사진 업로드 금지(완전 비식별만). 연구 데이터는 IRB/개인정보 규정 확인 후 사용.
