# IDEA-010 — SMAS flap이 mastoid와 deep temporal fascia(DTF)까지 닿지 않을 때 원인과 해결

- 기록일: 2026-10-15 / 제안자: 학습자 / 상태: 임상 문제, 문헌 1차 확인(직접 관련 논문 1편 확인)
- 연결: IDEA-009, IDEA-001(ligament release), 논문 2 노트(구획·ligament)

## 학습자의 원 발언
"스마스고정할때 마스토이드와 dtf까지 flap이 안가는데..박리를 적게해서 그런가 외 [오타]? 방법이 없을까"
※ 오타 부분은 "그 외 다른 이유가 있나"로 해석(확인 필요)

## 문헌에서 확인한 것 (PubMed 초록, 1개 질의, 결과 1건)
- Öreroğlu 2026, APS 50(16):6645-54 "Double-Sling Composite Facelift": SMAS flap 2개 sling 사용. **상부 sling flap**은 가로로 거상해 **temporal tunnel**로 통과시켜 **deep temporal fascia 내측**에 고정(중안면·관자 고정), **하부 sling flap**은 세로로 만들어 **귀 뒤로 돌려 mastoid fascia**에 고정(목 platysma·턱선). 기존 high-SMAS flap 벡터에 더해 3벡터. 72명(2019~2025), 39~75세, 수술 기법 증례 시리즈, 장기 결과나 대조군 비교는 초록에 없음 [V: PMID 42192009]
- 같은 논문의 서술: 진짜 중안면 이동성은 zygomatic ligament의 완전 release와 SMAS 적절한 안정화가 필요
- **못 찾은 것**: flap 길이·박리 범위와 도달 거리를 정량적으로 연구한 논문(이번 검색에서 못 찾음, 제한적)

## 가능한 원인 후보 [E: Claude 추론, 검증 전. 학습자가 판단할 사항]
1. 장력을 잡는 구조물이 남아 있음: sub-SMAS에서 zygomatic ligament, masseteric ligament, platysma-auricular 쪽 retaining 구조의 release 정도
2. flap 설계 자체의 길이·너비 부족(flap의 기저부 위치, 절개선 길이)
3. 벡터: 고정점이 너무 멀거나 벡터가 flap 이동 방향과 맞지 않음
4. 피부 flap 박리 범위와 SMAS 박리 범위를 혼동(피부 박리를 줄이는 것이 SMAS 도달 거리에는 직접 영향이 없을 수 있음)
- 학습자 가설(박리를 적게 해서)은 위 1번에 해당할 수 있음

## 해결 방향 후보 (문헌 + 추론)
- 문헌: Öreroğlu의 sling 방식(flap을 temporal tunnel로 옮겨 DTF, 하부 flap을 mastoid fascia로) [V, 초록 수준]
- 추론 [E]: 더 먼 고정점 대신 가까운 안정 조직에 고정, 불필요한 flap 일부 절제(SMASectomy 변형), release 추가 후 재측정

## 연구 설계 후보
- 수술 중 flap 도달 거리(고정점까지 mm)와 release 범위, 기법을 기록하는 간단한 기록지(2D 사진 필요 없음, 수술 기록 표준화)
- 목표: "flap이 안 닿는다"는 임상 경험을 정량 지표로 바꾸기

## 학습자에게 남은 질문

2. 하부(목쪽)와 상부(관자쪽) 중 어느 방향이 더 안 닿나?
