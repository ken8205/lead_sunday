# 수기 견인 검사 프로토콜 초안 (IDEA-001 + IDEA-006 통합)

상태: 초안 [E], 문헌 검증 일부만 됨. 실제 시행 전 학습자와 조정, 소규모 예비 자료(n=20~30)로 재현성부터 확인

## 장비 현황 (2026-10-06 학습자 확인)
VECTRA(3D) 없음 → **2D 프로토콜을 기본안으로 시작**한다. 3D 절은 참고용(향후 장비 접근 시). 지금은 같은 카메라·고정 거리·ImageJ·0~3 등급·평가자 일치도(kappa)로 예비 자료 20~30명을 목표로 한다.

## 목적
수술 전 앉은 자세에서 얼굴을 위·바깥으로 당길 때 꺼진 중안면, jowl, 외측 볼, NLF가 얼마나 채워지고 지워지는지를 표준화해 (1) 하강(descent) vs 결손(deflation) vs 고정(tethering)을 구분하고 (2) 수술 중 필요한 박리 범위와 치료 선택(당김 vs 볼륨)을 예측할 수 있는지 본다.

## 학습자 방법 (원 발언 기반, 2026-10-06)
- 방향: NLF와 jowl이 가장 예쁘게 없어지는 방향, 대체로 우상향
- 세기: 적당한 힘으로 없어질 때까지. 안 되는 환자는 세게 당겨도 잘 안 없어짐
- 자세: 앉은 자세
- 목표 부위: midcheek, lateral hollowness
- 잘 안 채워지는 환자: 마른 사람, 피부가 잘 안 당겨지는 사람

## 촬영 조건 (공통)
- 같은 방, 같은 조명, 자동 보정 끄기, 머리카락 고정(헤어밴드), 화장·필러 직후 제외 기록
- Frankfort horizontal(귀구슬-안와하연 수평선)에 맞춘 머리 위치, 시선 정면, 무표정(입 다문 이완)
- 거리·각도 고정(바닥 표시 또는 거치대), 촬영 방향: 정면, 좌·우 45°
- 상태 3개: (a) 앉은 중립, (c) 앉은 + 수기 견인, (b) 누운 자세(중력 반전, 선택)
- 환자 식별정보 제거(연구번호만), 사진은 안전하게 보관, IRB·동의 확인

## 수기 견인 표준화 [E]
- 손가락이 관심 영역을 가리지 않도록, 견인점을 귀 앞·측두 헤어라인 쪽 미리 표시한 지점에 두고 위·바깥으로 당긴다(관심 영역: NLF, 중안면, jowl, 외측 볼은 보이게 둠)
- 견인 방향 각도를 스티커 또는 선으로 표시해 매번 같은 벡터를 기록
- 힘: 측정 도구가 없으면 "당김 후 NLF가 사라지는 최소 힘"과 "최대 허용 힘에서도 안 사라지는 경우"로 구분 기록. 가능하면 힘 게이지로 힘 측정
- 검사자는 한 명, 같은 방식

## 지표 (손쉬운 순)
1. 견인 반응 등급 0~3 [E, 정의 초안]: 0 변화 없음, 1 약간, 2 뚜렷, 3 거의 완전히 사라짐. 부위별로 NLF, jowl, midcheek 꺼짐, 외측 볼 각각 기록
2. 2D 사진: ImageJ로 랜드마크(구각, NLF 시작·끝점, jowl 윤곽점) 이동 거리(mm, 눈동자 간 거리 또는 스티커로 축척), NLF 길이·각도, 윤곽선 변화
3. 3D: 중립·견인·누운 자세 표면을 안정 부위(이마, 코 기저)로 정렬한 뒤 관심 영역의 부피 차이(mL)와 변위 벡터
4. 수술 기록: ZM 통과 여부와 거리, zygomatic ligament·masseteric 느낌, 박리 평면이 열린 시점(템플릿 참조)

## VECTRA(3D)가 있을 때
- 선례: Ramesh 2021(ASJ 41(2):143-151)이 VECTRA H1으로 앉은 자세와 누운 자세를 촬영해 부피와 랜드마크 변위를 비교(초록 확인, 촬영 세부는 전문 미확인). Suwanchinda 2018(J Cosmet Dermatol 17(4):617-624, VECTRA의 VAM 모듈로 피부 변위 벡터 측정, 초록 확인)
- (a) 앉은 중립: 정면, 좌 45°, 우 45° 촬영 후 스캔 합성
- (c) 앉은 견인: 같은 거리·각도에서 조수가 표시된 점을 같은 벡터로 당긴 채 촬영. 손이 보이는 부위는 분석 영역에서 제외(마스킹)
- (b) 누운 자세: 침대를 수평으로, 머리 받침 높이·Frankfort 수평을 같게. 카메라는 머리 쪽 위에서 같은 거리와 방향을 맞춰 촬영(실제 방법은 Ramesh 전문 확인 필요)
- 분석: 안정 부위 정렬 후 관심 영역 부피(mL) 차이, 변위 벡터. 장비 소프트웨어 기능 확인 필요 [U]

## VECTRA가 없을 때 (2D로도 가능)
- 같은 카메라(또는 같은 스마트폰), 고정 초점거리(줌 사용 금지), 삼각대, 거리 고정, 축척 스티커(예: 알려진 길이의 표식을 얼굴 옆에 부착)
- 정면, 좌·우 45° 각 3장씩, 상태 (a), (c), (b)(선택)
- ImageJ(IDEA-002 방식 재사용): 랜드마크 이동거리, 각도, NLF 길이, jowl 윤곽선 이동. 부피(mL)는 못 구하므로 "표면 윤곽의 변화"로 해석
- 등급(0~3)은 사진을 섞어 눈가림 상태에서 두 평가자가 판정하고 일치도(kappa 또는 ICC) 계산
- 스마트폰 3D 스캔(깊이 센서) 앱은 정확도 검증 문헌을 아직 확인하지 않음 [U], 쓰려면 먼저 소규모로 재현성 확인

## 분석 계획 (통계 트랙 S4, S5, S10, S12와 연결)
- 반응 등급 vs 수술 중 박리 범위: 순서형 또는 로지스틱 회귀, ROC로 예측력
- 반응 등급 vs 연령, BMI, 피부 두께·탄력(피부 pinch 두께 등), 필러·수술 과거력
- 두 가지 비반응 유형 구분: (i) 마른 얼굴·결손형, (ii) 피부가 안 당겨지는 고정형 → 추가 지표(피하 두께, 피부 이동성)로 구분 가능한지 확인
- 검사자 내 재현성(같은 환자 반복 촬영), 평가자 간 일치도
- 표본 수: 예비 자료에서 효과 크기와 변이를 보고 계산

## 위험·주의
- 힘으로 인한 불편·멍(피부 손상 없는 범위), 사진 개인정보, 동의
- 수술자 눈가림 불가: 박리 범위 기록은 검사 결과를 보기 전에 정의한 기준으로 기록
