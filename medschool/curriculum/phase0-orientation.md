# Phase 0 — 오리엔테이션 (4주)

| 주 | 내용 | 산출물 |
|---|---|---|
| 1 | 진단 테스트(`00-diagnostic.md`) 응시 → `dean` 이 채점·해석, 모듈별 시간 재배정 | `progress/STATUS.md` 갱신 |
| 2 | 학습 과학 세션: 인출 연습·분산 학습·교차 복습(근거: Cepeda 2006, Roediger & Karpicke 2006, Dunlosky 2013), SRS 사용법 | 첫 카드 20장 |
| 3 | 시험 지형: USMLE·일본 국시 구조 설명, `exams/` 확인 필요 목록 점검 | 확인 체크리스트 |
| 4 | 시범 수업 1회(M01 첫 주제) + 주간 12시간 리듬 점검 | 실측 시간 기록 시작 |

## 학습 리듬 (권장)
- 평일: 아침/저녁 20~25분 `/review`, 정식 수업 2회(주 90분 × 2)
- 주말: 사전독서 + 주간 퀴즈 + 오답노트
- 진도가 밀리면 신규 학습을 멈추고 복습부터.

## 12주 보정 회의
12주차에 `dean` 이 실측 시간·정답률·오답 원인(K/R/M/C)을 분석해 일정을 재산정한다.
