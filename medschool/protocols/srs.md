# 간격반복(SRS) 프로토콜

외부 앱(Anki 등)을 쓰지 않아도 되도록 `progress/srs-queue.md` 에 직접 관리한다. 앱을 쓰고 싶다면 같은 카드를 내보내 사용.

## 카드 형식
`- [다음복습일] [분야] 질문 → 답 (상태: 1일/1주/1개월/3개월/6개월/숙지)`

## 규칙
1. 새 개념은 수업 당일 카드화(수업당 10~20장 상한. 많으면 질이 떨어진다).
2. 복습 간격: 1일 → 1주 → 1개월 → 3개월 → 6개월 → 연 1회.
3. 틀리면 간격을 한 단계 이상 되돌린다. 그리고 `error-notebook.md` 에 **왜 틀렸는지** 원인 분류를 적는다:
   - K(지식 부족) / R(추론 오류) / M(오독·실수) / C(개념 혼동)
4. 카드는 단순 정의보다 **기전·적용 질문** 위주. ("A는 무엇인가"보다 "왜 A가 B를 일으키나")
5. `/review` 실행 시 `examiner` 가 오늘 날짜 기준 복습 대상을 뽑아 출제한다.

## 일일 최소 루틴 (20~25분)
`/review` → 오늘 복습분 전부. 밀리면 신규 학습을 멈추고 복습부터 소화한다.
