# 수업 프로토콜

모든 교수 에이전트는 이 순서를 따른다. 한 회차 = 약 90분.

## 0. 시작 (5분)
- `progress/STATUS.md` 와 `progress/error-notebook.md` 를 읽는다.
- 지난 수업 핵심 3개를 **먼저 학생에게 회상**시킨다(인출 연습). 틀린 것은 오답노트에 반영.

## 1. 사전 독서 지정 (수업 전)
- 표준 교재의 **구체적 챕터/절**을 지정한다(교재명 + 장 제목). 확실하지 않은 장 번호는 임의로 쓰지 말고 장 제목으로 지정.
- 학습 목표 5~8개를 "~을 설명할 수 있다" 형식으로 제시.

## 2. 심화 강의 (35~40분)
- 현상 → **기전(mechanism)** → 임상 연결 순서. 암기 목록이 아니라 "왜"를 먼저.
- 질문을 던지며 진행(소크라테스식). 학생 답을 기다린 뒤 보정한다. 한 번에 한 개념 단위로 끊는다.
- 수치·분류·용량에는 확실도 표시(`[교재]`/`[근거]`/`[불확실]`).
- 영어 용어 병기. 일본 트랙 해당 시 일본어 용어도 병기.

## 3. 증례 토론 (20분)
- 실제 임상 시나리오(USMLE 스타일 vignette)로 기전을 적용. 감별진단과 다음 단계 질문을 포함.

## 4. 능동 회상 퀴즈 (15~20분)
- 해당 수업에서 5~8문항 + 이전 수업에서 2~3문항(교차 복습). 정답 즉시 해설, 오답은 기전으로 설명.

## 5. 마무리 (5~10분)
- 핵심 요약은 **학생이 직접 말하게** 한다(생성 효과).
- 근거 감사 대상 주장 목록(`audit-list`)을 남긴다.
- `progress/` 갱신: 진도, 정답률, 오답 항목, 다음 복습일(간격: 1일·1주·1개월·3개월).

## 모듈 종료시험 기준
- 문항 40~60개, 교차 복습 문항 20% 포함.
- **정답률 80% 이상** 통과(권장). 70~79%: 약점 영역 재학습 후 재시험. 70% 미만: 모듈 재수업.
- 기준은 12주 보정 시 조정할 수 있다.

## 하지 말 것
- 교재 목차를 나열만 하고 끝내는 요약식 수업
- 근거 표시 없는 수치 제시
- 학생이 이해했다고 가정하고 진행 (반드시 회상으로 확인)
