# 일본 의사국가시험(医師国家試験) 트랙

> 이 문서는 학습 설계용 개요다. **자격·절차·시험 형식은 후생노동성(厚生労働省)의 최신 공지로 직접 확인**할 것.
> 아래 일부는 기억에 의존한 `[불확실]` 정보다.

## 알려진 것 (일부 불확실)
- 시험은 일본어로 시행. 필기 중심의 객관식 `[불확실: 현행 문항 수·일정·합격기준은 최신 공고 확인]`.
- 출제 범위는 후생노동성이 공개하는 **「医師国家試験出題基準」** 에 정리되어 있음. 과거 시험 문제도 후생노동성 사이트에서 공개되는 것으로 알고 있음 `[불확실]`.
- 외국 의과대학 졸업자의 응시는 별도의 **수험자격 인정** 절차가 필요한 것으로 알고 있음 `[불확실]`. 한국 의대 졸업자의 구체적 조건은 직접 확인.

## 확인 필요 목록 (사용자)
- [ ] 외국 의대 졸업자의 수험자격 인정 절차(예비시험 여부, 서류, 언어 요건)
- [ ] 한국 의사면허 소지자에 대한 현행 취급
- [ ] 최신 「医師国家試験出題基準」 PDF 다운로드 → `curriculum/map.md` 와 대조
- [ ] 최신 시험 형식·일정·합격기준
- [ ] 일본어 현재 수준(진단 필요: 의학 일본어 별도 평가)

## 학습 설계
- **일본어 의학용어 트랙**: Phase 2부터 주 +1시간. 영어 용어 ↔ 일본어(漢字/カタカナ) 대응표를 모듈마다 생성
  (`coach-japan-jmle` 담당, 결과는 `curriculum/jp-terms/`).
- **차이 대조**: 일본 가이드라인·보험·법령·공중보건 항목은 미국/한국과 다르다. Phase 3.5에서 별도 학습.
- **문항 형식 적응**: 일본어 임상 vignette 읽기 속도 훈련. 과거 문제는 공식 공개 자료를 사용자가 내려받아 제공하면
  에이전트가 오답 분석·해설을 담당(원문 복제 대신 요지 중심).
- **상시 보조**: 일본 환자 상담에서 쓰는 어휘와 시험 어휘가 겹치는 부분(피부·성형·마취·창상)부터 시작하면 동기 유지에 유리.
